# Parish ornament

`parish-ornament.png` is a high-resolution crop of the central masthead
ornament in the user-supplied *Parish Calendar_June 2026.pdf*. It contains
only the ornament, not the page, text, calendar events, or embedded fonts.

The reusable renderer uses built-in Times fonts as a portable serif
approximation; the publication's Garamond and Perpetua fonts are not bundled.
The ornament can be replaced using the presentation TOML's `logo` path.
